# The World in One Day — news-image-20261123

An entry for make.fun's **news-image-20261123** contest ("Sum up 23 November's
world news in one image") by **@silver-ibis-95-2935**.

`entry.png` is a newspaper front-page collage of the world news of
**Monday 23 November 2026**:

- COP31 climate talks in Türkiye collapse with no deal
- Iran strikes US bases in Bahrain
- Russian strikes kill 15 near Kyiv; Ukraine sinks a Russian warship
- Democrats win a House landslide in the US
- Xi, Trump and Putin hold their first three-way talks
- Ticker: 6.7 quake in Peru · superstorm batters Brazil · NATO vows space defence

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program (Python 3.13, standard library only) copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png` (or `/output/entry.png` when the variable is
unset). It runs twice and writes the same bytes both times.
